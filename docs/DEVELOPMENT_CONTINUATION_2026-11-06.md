## 已修复

1. **避免执行结果不明时再次请求模型。** 旧降级逻辑按错误文本片段匹配，服务断连、发送异常都会启动本地模型回复。现在只接受三种明确发生于模型执行前的失败，并校验 runId、操作类型、结果、上下文快照和恢复引用。服务断连或发送结果不明时保留 Runtime 恢复路径，不以新回复覆盖待恢复结果。
2. **保持压缩和回复改写的操作语义。** 压缩、改写及已完成的运行不能进入普通聊天降级路径；服务绑定失败返回的结果保留请求的 runId、operation 和 rewriteTargetMessageId。
3. **真正关闭降级模式的工具。** 除原有配置开关外，统一过滤全部工具 schema，关闭服务端网页搜索、搜索建议，并清除可能重新注入工具的自定义请求体。保留拒绝工具执行的兜底执行器。
4. **停止按钮可取消本地降级回复。** 降级回复使用可由会话运行存储取消的 controller；停止早于降级启动、晚于降级启动以及运行已移除的情况都有覆盖。模型事件同步投递到主线程，保持事件先于最终结果的顺序。
5. **修正 Windows 数据库重开测试的后端。** 原有重开测试在默认模拟 SQLite 后端下丢失存储，改为原生 SQLite 后恢复通过。只调整该测试的运行方式，没有修改生产数据库逻辑或跳过持久化断言。
6. **修复 4 处 Compose 资源读取错误。** 归档检查提示和会议室创建错误提示改为配置感知的字符串读取；异步创建失败使用最新翻译。原有布局、样式和交互保持一致。
