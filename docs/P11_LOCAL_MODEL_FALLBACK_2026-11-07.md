# P11 小模型与终端基础

新增模型故障分类与回退策略：网络、限流和服务端暂时故障可以在用户已启用且已配置备用模型时回退；鉴权和请求配置错误必须先由用户修复。回退默认关闭工具权限，避免小模型在降级状态执行设备或文件副作用。

补齐运行边界：只有原请求尚无输出、工具、补充指令或压缩进展时才能重新发起文字降级。非聊天操作、额度不足、未知异常和权限缺失不会自动切换。已执行任务保留原失败及 transcript；备用请求使用独立无工具用途和拒绝执行器，清除自定义工具请求体，并从后续轮次开始。

**本批未完成**：安全文字降级不等于执行中跨模型接续，也不等于端侧模型引擎；能力/预算检测、终端完整缺口及真机测试继续保留。

P11 与 P12 已达到双批交付出口，当前安装包包含本批安全回退和 A2A 网络策略。
