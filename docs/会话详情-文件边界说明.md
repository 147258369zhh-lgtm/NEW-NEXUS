# 会话与会议室详情：项目文件边界

- 项目文件页独立懒加载，只在打开该标签、手动刷新或完成导入后读取，不依赖运行统计读取完成；退出文件标签时取消读取。不存在常驻磁盘轮询。
- 当前主体按明确的 conversation / meeting 标识读取文件账本与已发送输入栏附件。关联项目仅补充项目层明确导入的共享输入，不显示其他会话或会议室的输出。未归属主体的旧输出不会通过文本路径猜测补入。
- 文件账本记录保留。读取时检查文件可读性；已失效、当前权限不可读、尚未验证或验证失败的记录仍显示状态，但禁用预览、导出和分享。可读状态是读取时快照，文件后续变化仍可能导致打开失败，并显示错误。
- 输入栏目录引用显示目录名称、路径与状态说明；当前版本不递归扫描目录，不预览或导出目录内容。目录行是来自当前主体消息的明确引用，不冒充已验证文件作品。多个文件导入使用文件选择器，不导入目录树。
- 仅当前可读的普通文件引用进入持久文件账本。历史中的不可读普通文件若从未入账，暂无法建立可验证条目；已经入账的文件失效后仍保留记录。
- 输入图片逐张显示，已有文件 / content URI 或有界 data URL 转为可预览的输入作品；单张解码上限 32 MiB。图片实际 MIME 通过文件头识别。
- 大小展示使用 artifact.sizeBytes；未记录大小时显示“大小未记录”，不把未知大小写成 0。导出和分享复用作品访问器，在 IO 线程复制，使用作品 MIME，并显示失败原因。
- 模型分布保留未知 Token 与不完整用量状态。运行统计、运行监测使用主体记录的实时流；点击趋势时间段仅筛选下方运行记录。

本次仅做源码及静态检查，未编译、测试、打包或在设备验证。
