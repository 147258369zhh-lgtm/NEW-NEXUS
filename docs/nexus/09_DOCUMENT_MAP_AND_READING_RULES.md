# 蓝图文件关系与阅读规则

## 权威层级

1. **当前交接入口**：`00-当前开发交接-2026-11-12.md`。新会话第一份只读它。
2. **当前完成度**：`10-完成与未完成矩阵-2026-11-12.md`。判断下一步和未完成项。
3. **当前执行计划**：源码 `docs/nexus/31_V6_EXECUTION_PLAN_2026-11-12.md`。D01-D14 工作包与验收。
4. **滚动实装进度**：源码 `docs/nexus/22_IMPLEMENTATION_PROGRESS_2026-11-10.md`。最近批次、证据、交付。
5. **需求原文**：`05`、`06`。用户确认内容不得用摘要覆盖。
6. **决策记录**：`07`、`08`。新用户消息优先于旧决策。

## 文件关系

```text
00 当前交接入口
├─ 10 完成与未完成矩阵

研究依据

├─ v6-需求承接与差距矩阵
└─ v6-研究来源与代码证据

历史追溯，不再作为开发入口
├─ Nexus-Development-Blueprint-v3/v4/v5

├─ 02-版本演进与执行顺序
├─ 03-历史需求与设计偏好
└─ 04-文件校验与资料来源
```

## 各文件作用

| 文件 | 作用 | 是否默认读取 |
|---|---|---|
| `00-当前开发交接-2026-11-12.md` | 唯一新会话入口、交付与下一步 | 是 |
| `10-完成与未完成矩阵-2026-11-12.md` | D01-D14 实际完成度与剩余项 | 是 |
| `09-文件关系与阅读规则.md` | 本目录结构说明 | 首次交接读一次 |
| `Nexus-V6-执行计划-2026-11-12.md` | 桌面副本；源码 docs 版本的副本参考 | 与源码冲突时只读源码 |
| `Nexus-Development-Blueprint-v6-2026-11-11.md` | 总体架构与研究蓝图 | 需要架构依据时 |
| `v6-现状审计与新需求承接-2026-11-11.md` | 初始代码审计与新需求承接 | 追查来源时 |
| `v6-需求承接与差距矩阵-2026-11-11.md` | 342 个原始编号映射 | 查具体编号时 |
| `v6-研究来源与代码证据-2026-11-11.md` | 开源项目、规范、许可证和代码位置 | 调研引用时 |
| `05-用户完整开发需求书-原文` | 第一至十五部分原文 | 需求争议时 |
| `06-主会话原生渲染需求-原文` | 第十六部分与跨平台 | 多媒体相关时 |
| `07-v6意图澄清与决策记录` | 已确认行为 | 行为争议时 |
| `08-官方模型计价与自动授权补充` | 价格、预算、电脑权限决策 | 对应任务时 |
| `01`、`02`、`03`、`04` | 历史沟通、版本演进、偏好、校验 | 默认不读 |
| `Nexus-Development-Blueprint-v3/v4/v5` | 历史版本原件 | 仅追溯，不重做 |

## 新会话规则

- 不粘贴旧会话全文；给 `00`、`10` 路径和本次 D 编号即可。
- 先 `rg` 定位，再只读相关实现、测试与调用者。
- 需求原文和当前源码冲突时，以最新用户消息和当前生产代码证据裁决。
- 完成一项后只更新源码/31与源码/22；只有交接层级变化才更新 `00`、`10`。
- 历史文件不改写，以免制造多套相互冲突的“最新计划”。
