# Nexus 计划差距收口（2026-11-10）

本文件记录本轮对总计划剩余项的收口。它区分“源码已闭环”“已通过构建门禁”和“仍依赖外部条件，不能宣称完成”。

## 本轮补齐

- 工作流模式按会话写入 `GoalPlanNotepadStore`，重新打开会话时恢复 `CHAT/PLAN/GOAL`，并继续随 Run Handoff 注入 Runtime。
- 输入框上方加入可折叠 Goal/Plan 卡，展示目标状态、计划 revision、步骤、验证方式和软预算。
- 记事本从普通弹窗升级为会话顶部下拉抽屉，支持半屏/全屏和 900ms 自动保存 Revision；整理、总结、生成计划、执行均显式交给当前 Agent。
- 新增统一 `NexusContentPartRenderer`，覆盖 Text、Markdown、Math、Code、Image、Audio、File、ToolTrace、PlanCard、UserInput 和 Approval。音频使用异步准备，审批和用户输入具备交互回调。
- LocalVoiceSessionCoordinator 把现有语音流程同步到 canonical `VoiceStateMachine`，Overlay 同时暴露 canonical snapshot。
- 影子执行账本增加 30 天/最多 200 Run retention，以及 `readTimeline(runId, afterSequence)` 调试读取入口。

## 本轮验证

- `checkNexusArchitecture` 通过。
- `:app:compileDebugKotlin` 通过。
- `:app:assembleRelease` 通过，生成 48,476,327 字节的 `Nexus-v0.1.0.apk`；`apksigner verify` 确认该文件未签名，因此不能作为正式发布包。构建成功不等于真机验收。

## 仍未完成且不能伪装的门禁

- DSH Host 本体和全部 UI 插槽：仓库当前只有 Slot 合同，没有可验证的 DSH Host 协议实现或运行包，因此稳定版不得宣称支持 DSH。
- 影子 Event Ledger 主事实源切换：必须先完成至少 20 Run 与旧 Metrics/Checkpoint 的零差异对照，当前只能影子记录，不能驱动恢复。
- 迁移向导已接入迁移与备份页；跨设备的 Keystore 重新包裹仍需第二台真机验证。
- 双向 A2A：入站、出站、标准/别名、动态 Agent Card 和前台服务已在源码中；仍需要两个真实对端完成跨网、锁屏、后台与重启联调。
- 全双工语音：canonical 状态机已经接线；真实 AudioRecord、AEC、流式 ASR/TTS、锁屏和不同 ROM 仍需要真机验收。
- 正式签名：当前环境没有 `NEXUS_RELEASE_*` 签名配置或可用 release keystore。不能生成标识为正式发布的可安装签名包，也不能擅自新建证书替换未来升级签名。
- 真机全量验收：息屏、锁屏、最近任务划掉、Doze、重启恢复、Classic/Omni 两套视觉效果和长时稳定性仍需设备证据。

## 下一道可执行门禁

5. 在目标真机完成语音、后台、归档、备份恢复及两套 UI 的验收矩阵。
