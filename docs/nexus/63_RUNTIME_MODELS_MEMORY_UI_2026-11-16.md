| 项目 | 实际实现与边界 |
|---|---|
| 1. 普通会话、会议上下文压缩 | 预算同时考虑系统提示、工具目录、历史、图片与服务商报告；巨型单条内容计入 JSON 转义开销后分块；摘要模型与备用模型各按自己的真实窗口限制输入输出。压缩后重试使用新上下文；保留最近已完成答复及原始存档，失败不覆盖原始上下文。不能把单元用例当作每家服务商的真实长会话验收 |

| 4. 角色与指令 | 保留原功能与返回位置。模板、作用域、导入与导出、治理各有职责；重复行为方案仅在治理展示。新增可展开、按当前页说明实际操作与注入环节的专用说明区，不把相同卡片堆在多个标签下 |
| 5. 本地模型与本地语音 | 新增经核验的官方 MiniCPM4 0.5B QAT Int4 GGUF；导入校验架构、词表、模板与文件完整性。加强 MNN 目录依赖核验、预热取消、GGUF GPU→CPU 后停止衔接。修复一次性 ASR 只保留最后一段，限制音频输入输出，空闲卸载语音引擎，设置仅显示后端实际生效参数。详见下方兼容性报告；不宣称 MiniCPM-V/o/ASR 已支持 |

| 7. 创建会议室 | 默认只展开已选主持和成员，换主持/预选成员时展开候选，减少打开即看到两大串重复 Agent。成员卡用既有鲜亮头像与连续圆角、精简重复说明，模型分配集中在下方；保留用途选择、临时主持与已选模型校验，不变更其他会议界面 |
| 8. 资源额度可续增 | 软/硬额度、模型请求数及可核对费用耗尽可再次申请有限增量；通过持久审批回执提交并传播。保留 run 身份、已花费的轮数/工具/时长/Token/费用，后续再耗尽可再申请；拒绝、超时、取消退出。增加时长后工具发现和子 Agent 用更新期限。不会修改未来任务模板或把未知计费当作零 |
| 9. 软件管家 | 输入区跟随键盘；键盘发送与按钮一致。修复固定头部导致的滚动目标偏移、配置读取异常、停止运行占用主线程，以及阻塞等待取消衔接。诊断任务先区分配置/权限/网络/模型/资源，继续遵守用户 UI 授权规则 |
| 10. 语音输入波形 | 替换为青蓝紫交叠复合波形，透明画布、随音频能量和样本变化；暂停/继续居中，确认仍在下方，文字继续进入原输入框。每帧相位只在绘制阶段读取，停止时不持续刷新；不重做语音配置页 |
| 11. 问题时间轴 | 聊天、会议共用静止细线，长按拖动显示刻度与问题摘要，松手定位。节点为用户问题。普通聊天跨历史定位使用轻量问题索引及每次 128 条的只读分页窗口，可看上一段/下一段/回到最新；不替换正在运行的会话与压缩上下文。切会话隔离索引，陈旧异步结果不串入新会话，流式 token 不反复合并全历史问题列表 |
| 12. 能力中心导航 | 一级为概览、Skills、连接；来源管理进入 Skills 设置，不再占一个空泛一级标签。概览统计已启用的 MCP/API/通用连接/A2A 等实际记录，不发网络探测或把凭据计作能力；连接继续承载已有服务 |
| 13. A2A 细化权限 | 保留只读/受限预设和旧记录；可按本机可配置的具体工具编辑清单，绑定当前 token 指纹。每次调用复核原任务授权与当前授权交集，撤销生效，后来扩大授权不扩张旧任务。既有远端高危限制和 Android 权限仍有效；没有虚假的项目/效果授权开关 |
| 14. 在线文生图 | 模型页新增同步 Images-compatible 端点/API Key/模型设置，接入实际工具与会话/会议成果管线；支持 base64 或公开 HTTPS 图片结果，校验格式、字节数、尺寸，密钥独立加密。结果未知/重复请求不自动再付费。不宣称适配所有厂家、异步生图或图片编辑 |
| 15. 记忆读取失败 | 记忆入口初始化惰性角色库，避免尚未打开角色页就读取全目录失败；分类数据源独立容错，模型配置/开关读取故障不阻断本地文档。AtomicFile 中断写入的 `.bak` 可恢复；读取过程施加 1MiB 上限，超限不删除原文。已核对学习库迁移，没有证据时不擅自改版本或重建数据库 |
