## 软重启行为

入口为“设置 → 系统与工具 → 工具功能 → 软重启”。这是一次性动作，不写成开机偏好。用户确认后请求Root并调用受支持的KernelSU `ksud soft-reboot`，不切换到整机重启。重复请求在执行中合并阻止；没有支持接口或Root时显示真实失败原因，不自动重试。

当前只接入58号记录在本机验证过的KernelSU用户空间重启路径，不声称支持所有Root管理器。真正重启会中断运行中的任务；本批检查使用假执行器，不能把软件侧检查当成真实手机重启验收。

## 实际实现

### 记忆分类和经验库

记忆文档页始终显示全局、项目、会话、任务、会议、角色六类。选择类型后列出真实对象名称；没有对象时显示空状态，不创建虚假文档。角色打开原有剧情记忆页。文档可按全文、前言和各章节查看编辑，未编辑的前言、未知章节及其他原文保留；范围切换、刷新和保存沿用草稿及版本冲突保护，并补加载竞态防护。

自学习页明确为经验库，保留候选、质量审核、确认、生效、版本及回滚；候选和规则补scope列，去重、冲突、晋升与检索均按范围处理。Learning数据库4→5只加列和替换索引，旧条目保持global，ID、版本、证据不变。完整备份保留新字段；同时修复备份清单中meeting及conversation_extensions落后真实Room版本的问题。清单核对8库：core30、conversation_extensions7、meeting7、learning5、tasks5、a2a5、projects2、metrics4。

主任务与子任务通过同一选择器先限制合法范围、active/未过期条目，再按任务关键词选择、去重及整条分配。默认128k窗口总预算5333字符，核心常驻最多1200；无关内容不填满预算。4096窗口总170字符，短核心仍能整条选入，完整版本元数据保留但不每条注入64字摘要。小模型紧凑装配继续按完整条目提供。记忆关闭而经验库开启仍独立生效；角色运行不暴露现实学习工具，也不自动提交现实失败候选。

### 角色与指令、注入环节

集中入口管理行为方案，完整剧情人物资料作为可选模块，原角色卡字段、头像、收藏、开场白、用户人设、世界书、剧情记忆、完整PNG/JSON导入导出与备份沿用原所有者。真实工具边界复用AgentBoundaryStore，不靠提示词扩大权限。

新增项目范围和指令块阶段：普通对话、会议规划、会议工作、会议协调、会议汇总、会议访谈、子Agent、自动任务。绑定可追加、替换继承或在当前范围停用；按具体范围优先分配完整块预算，标明未纳入原因。角色宏按实际上下文展开，缺少对象/未知宏不静默注入原占位符。模板与角色后置统一为当前输入后的临时用户提示，重写、图片附着、续接和世界书扫描排除这些临时消息。

本地组装预览可选择模型、对象、阶段，直接使用生产Resolver，不调用模型或读取凭据。最近记录在真实Provider入口采集组装后元数据，显示来源、阶段、位置、继承、预算状态和公开工具；不存输入、密钥或提示词正文，仅存ID、来源、长度、摘要和索引。记录明确属于提供商转换前请求，不等同服务端最终载荷。压缩、记忆提取、技能提炼、语音整理等专用辅助环节继续使用专用指令，界面说明它们不受普通模板统一控制。

指令配置schema2兼容读取schema1，Markdown/TXT往返保留阶段；未知阶段不生效、未知继承模式保守停用。主持人单独模板的真实作用域已保留身份，运行映射同步辨认主持，不靠空参与者字段猜测。

### 默认主Agent与专业岗位

内置1位主持协调，以及文件探索、网络研究、事实核验、方案规划、编码实施、独立审查与验证、数据分析、写作、编辑与翻译、文档制作、个人资料助理、设备诊断12专业岗位。原explore/coder/plan标识保留，新内置名称与既有用户模板碰撞时保留用户定义。

全局默认主持持久化，新会议默认使用它，专家由用户多选；不批量覆盖旧会议的明确主持或模型绑定。可在创建会议时新建临时主持职责，快照仅保存在此会议的创建事件内，运行、复制和完整备份沿已有事件存储回读，不自动污染全局模板。

主持职责实际参与规划、协调、访谈、工作和汇总装配，但各阶段的工具限制及真实用户回答要求保留。岗位有中文名称、职责、输入输出、停止条件、工具和预算差异；模型尊重显式绑定，复用既有路由和能力权重，不冒称拥有专业胜任率/价格/速度实测排行。个人资料岗位补接旧消息、联系人、日历等真实只读工具，并与权限编辑共用分类。
