## 已授权范围

6. 盘点可在聊天/会议室内部打开的文件，区分真正内置与仅识别/外跳。

## 文件就地打开能力盘点

会话和会议室使用同一消息/附件渲染链；以下为源码可达能力，不表示已在手机对所有格式验收。

| 文件类型 | 内部打开方式 | 边界 |
| --- | --- | --- |
| PNG/JPEG/BMP/WebP/GIF | 原生消息内预览，点击内置图片查看器 | 静态解码受像素、尺寸及输入大小预算约束；展开的动图当前取静态帧 |
| HEIC/HEIF/AVIF | 原生图片入口，调用系统解码 | 依设备实际支持；失败仍保留文件保存/外部打开 |
| SVG | 安全静态SVG原生渲染 | 禁脚本、事件、外链、动画与复杂滤镜；交互SVG代码作品走单独网页入口 |
| GIF/动态WebP | 消息内受限动画 | 限2MiB、帧数/像素预算；超限退静态，不承诺展开继续动画 |
| MP3/M4A/AAC/OGG/Opus/FLAC/WAV/AMR | 内联音频播放器 | 容器与轨道仍需设备解码支持；失败可保存/外跳 |
| MP4/M4V/WebM/MKV/3GP/3G2/MOV | 内联视频、首帧及全屏 | 不保证每种容器中的全部编码；AVI仅类型识别，不在原生播放候选内 |
| HTML/XHTML及HTML/SVG作品代码 | 独立内置作品网页 | HTML源码2MiB上限；已验证产物可带受限同主体依赖。普通上传HTML不自动收集相邻依赖 |
| TXT/Markdown/源码/XML/YAML/LOG等 | 内置只读文本/代码 | UTF-8、有界分页：每页16KiB、最多128页；消息Markdown另有标题、列表、代码、表格、公式与脚注 |
| CSV/TSV | 内置只读表格 | 读取前2MiB，最多1万行/128列/每格4096字符 |
| JSON/+json | 内置折叠树，超限退文本 | 树解析512KiB、64层；展示按需展开并限制深度和条数 |
| ZIP | 内置只读目录 | 压缩源32MiB、最多1000项、声明展开量256MiB；不自动解压或执行 |
| PDF/Word/Excel/PPT | 文件卡及外部应用 | 没有完整的内置文档页面渲染；通用文本或字节兜底不是文档预览 |
| RAR/7z/TIFF/SQLite/数据库/3D/字体等 | 文件卡、保存、外部打开及适用的字节兜底 | 识别类型不代表内置专业查看器 |
| APK | 文件卡交系统安装器 | 用户点击后进入系统流程；缺来源许可先交系统设置 |
| 未知二进制 | 通用文件卡，前4096字节预览 | 不执行文件；仍可保存/外部打开 |

图片常规读取12MiB；本地大小已知file/content可直接有界采样至256MiB。原生静态预览最多200万像素/2048边；本地可寻址JPEG/PNG/WebP额外支持单区域最多100万像素解码。全图适屏放大只是绘制尺寸变化，不按屏幕放大分配整张原图内存。

只支持真实可读附件与已验证产物；目录、越权路径或不可读文件不伪装成可打开文件。PDF/Office若未安装接收应用，保留保存和提示，不能称为已内置。

## 实施与检查

已完成本轮授权范围内的源码修改：

- 首页清空原顶栏标题，避免会议名透到居中的会话/会议室切换按钮下；未改按钮布局。
- 会议参与者与会议列表头像接专用六组明亮同色渐变，其他头像保持不变。
- 新增共享活动小点：实际运行绿色轻呼吸，未运行按本地日历今天橙、昨日前天红、更早灰；监听日期/时区/前台等变化，关闭侧栏停动画，不逐行轮询。会议真实运行集合由协调器事件投影，覆盖排队与恢复链路。仅小点采用本轮规则，选中行底色/边线未顺带改变。
- 图片查看器默认保比例居中适屏，可切原尺寸并缩放/双轴滚动；小图返回原始尺寸。放大只改变绘制尺寸，采样及单区域100万像素预算保留；旋转/镜像JPEG或尺寸比例不匹配时禁区域覆盖，保留正确底图。消息内小图及音视频组件未改。
