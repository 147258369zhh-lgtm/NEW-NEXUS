# NEXA UI Foundation v1.4（2026-11-14）

## 状态与范围

本文定义 NEXA 的组件级视觉与交互基础，并记录 v1.4 的 Android 视觉适配：皮肤入口收敛为两套、默认切换为经典、连续曲率形状进入关键控件、状态色和裸图标更新、经典三套字体预设收敛、语音主视觉接入真实时域波形。源码扫描用于确认组件碎片化程度。

最终皮肤只保留两套：

1. 经典：稳定、清晰、近原生，适合长期使用。
2. 液晶玻璃：主输入区、浮动控制和临时浮层具有可辨认的背景采样、受光与折射表现，文字和图标保持独立可读层。

两套皮肤共享全部布局、尺寸、图标、状态、触控、动效和业务语义。切换皮肤只能改变明暗、色相、填充、阴影与折射，不能改变信息结构。

## ColorOS 17 参考结论

用户提供的 9 张 OPPO ColorOS 17 截图放在 C:\Users\29136\Desktop\OPPO。只提炼完成度方法，不复制私有组件或宣称复刻其官方 token：

1. 页面底色是偏冷的近白珍珠雾，真实取样集中在 `#F0F1F3`；内容卡保持 `#FFFFFF` 或 `#FDFDFD`。两者不是同一种灰。
2. 设置分组是一块连续纯白面，组内用 0.5dp、低对比发丝线分隔，不把每行再套一张卡。
3. 设置图标多为裸露的彩色或灰色字形，没有统一圆底。
4. 每个局部任务通常只有一个强色动作，例如橙色或蓝色按钮。
5. 图标线宽和视觉重量偏轻，点击区域通过行高与留白补足。
6. 翻译、计算器、录音等页面允许局部形态不同，但共享的留白节奏、字号、图标语言和操作层级保持一致。
7. 少量冷光和暖光只改变画布气质，不覆盖卡片。高级感来自光学秩序，不来自每层玻璃、每个图标底圈、每条粗描边或大面积灰化。

## 材质层级

| 层级 | 用途 | 填充 | 实时模糊 | 边界 |
|---|---|---:|---:|---|
| M0 Canvas | 页面背景 | 珍珠雾白；经典约 `#F0F1F3` | 0 | 无；只承载极弱局部光 |
| M1 Group Surface | 设置组、列表组、普通卡片 | 经典 `#FFFFFF`；玻璃 58–76% | 0 | 0.5dp、6–10% 发丝线 |
| M2 Field | 普通输入、搜索、单行字段 | 48–70% | 0 | 轻微内阴影；聚焦 2dp 语义环 |
| M3 Focal Control | 每屏唯一主输入区或主浮动控制 | 42–76% | 22–30dp | 局部顶部受光 + 底部极轻暗影 |
| M4 Overlay | 菜单、面板、弹窗 | 84–94% | 24–30dp | 轻渐变边与单向柔影 |
| M5 Scrim | 模态阻断 | 38–58% | 4–8dp | 无额外边界 |

强制规则：

- 普通分组不能每卡实时模糊。
- 经典普通分组必须是纯白内容面，不能继承画布灰；阴影只提供 1–2dp 接触感，不能用大面积灰影代替层级。
- 每屏最多一个持续背景采样区；打开浮层时可增加一个临时采样区。
- 取消闭合式高亮外描边。状态胶囊采用“轻微凸台”：半透明语义底、顶部内高光、底部细暗面，不画明显外边线。
- 文字、图标和图片不进入折射绘制层。
- 液晶玻璃皮肤也不代表整页透明；设置分组始终安静。

### 液晶玻璃的可见实现链

1. 采样玻璃后方的滚动内容，并限制采样区域；每屏最多一个持续采样面。
2. 对背景做降采样与模糊，再调整亮度和饱和度；`regular` 调整背景明度，`clear` 只用于视觉丰富的背景。
3. 在玻璃层叠加半透明白色、局部镜面高光与底边内阴影，形成真实厚度。
4. 只在边缘叠加轻微色散/折射扰动；正文和功能图标始终位于独立的清晰合成层。
5. 性能不足、系统关闭模糊或设备不支持时回退到静态玻璃，同时保留底色差、受光与层级。

## 空间、字体、形状与状态

空间使用 4dp 网格：4、8、12、16、20、24、32、40、48dp。页面左右 16dp，分组间距 24dp，行内边距 16dp，列表行最低 56dp，弹层内边距 20dp。

字体只保留六种角色：

| 角色 | 字号/行高 | 字重 |
|---|---|---|
| Display | 34 / 40 | 600 |
| Title | 24 / 32 | 600 |
| Item | 16 / 24 | 550 |
| Body | 15 / 23 | 400 |
| Support | 12 / 18 | 400 |
| Caption | 11 / 16 | 400 |

经典皮肤内提供三套字体气质，字号、行高、字重区间与布局完全不变：

1. **系统原生 / SF-inspired**：Windows 使用 Segoe UI Variable，Android 使用 Roboto，中文按系统字体回退；中性、克制、适合高频操作。
2. **清润人文 / Manrope**：随包使用 OFL 授权的 Manrope 处理英文与数字，中文回落到系统合法字体；比原生字形更轻、更开阔。
3. **书刊阅读 / Newsreader**：随包使用 OFL 授权的 Newsreader 处理英文标题，中文标题回落到 Songti 一类系统书刊字形；正文保持系统无衬线。

不内嵌或分发 Apple SF。Manrope 与 Newsreader 的 OFL 许可证随 APK 与设计包一并交付。所有预设继续支持 Dynamic Type/系统字号、200% 字体与窄屏换行。

圆角令牌：12、16、18、24、30、34、44、999dp。经典皮肤使用三次贝塞尔切线连续的连续曲率，曲率从直边渐进加速进入转角再平滑离开；不采用“半圆 + 两条直边”的普通圆角观感。输入面板、输入底座与发送键全部使用这一套形状。玻璃皮肤可把曲率指数略微调方，但发送键仍为完整圆形、面板四角连续。

所有可交互角色至少定义以下状态：默认、按下、聚焦、选中、禁用、加载、错误、成功。字段额外包含空、已填、只读与验证中。聚焦环为视觉边界外 2dp；禁止只靠降低透明度表达禁用、加载和错误。

## 图标格式与裸图标规则

界面功能图标的唯一设计源格式是 Material Symbols Rounded SVG。Android 落地使用 Compose ImageVector；通知、启动器等原生入口使用 Android Vector Drawable XML。

资产规则：

| 类型 | 允许格式 | Android 表示 |
|---|---|---|
| 功能图标 | SVG | ImageVector 或 VectorDrawable |
| 品牌/模型 Logo | SVG 优先，必要时 WebP/PNG 多倍图 | BrandLogo 组件 |
| 复杂动画 | Lottie JSON 或 AnimatedVectorDrawable | 受 Reduce Motion 和性能档控制 |
| 图表 | 代码生成矢量或 Compose Canvas | Canvas/Path |
| 禁止 | 功能图标 PNG、GIF、字体字形冒充图标 | 不进入正式资源 |

光学尺寸：16dp 行内、20dp 导航、24dp 默认、28dp 大图标或空态；视觉线宽 1.55–1.85dp，圆端点与圆连接。每个能力使用一个鲜亮的语义色：蓝 `#3C8CFF`、紫 `#8B6CFF`、青 `#24BFD4`、薄荷绿 `#27C47B`、黄橙 `#FFB13B`、珊瑚 `#FF607C`、粉 `#FF60A8`、蓝紫 `#4A7DFF`。图标只使用发丝级阴影与极淡径向受光形成精致感。

默认状态必须裸图标。无意义圆底、方底和彩色底板全部取消。允许出现容器的例外只有：

1. 按下或焦点反馈。
2. 状态徽标。
3. 品牌 Logo。
4. 真正独立且浮在内容上的功能入口。

设置页图标、菜单图标、能力入口图标和普通工具图标不再套底圈。视觉图形通常 20–24dp，点击区由父组件补足到 48dp。Android 的 `EtaIconTile` 保留兼容名称，但内部已改为彩色裸图标、发丝阴影和极淡径向光，不再绘制渐变方底、边框或阴影容器。

方向语义会变化的图标使用 AutoMirrored。每个可交互图标必须有可读名称；纯装饰图标从语义树移除。

评审 HTML 新增 30 个实际渲染的“图标能力图谱”，覆盖会话、会议室、新建会话、统一列表、设置、添加能力、外观、思考强度、上下文、语音、模型、发送、停止、搜索、文件、文件夹、图片、MCP、Skill、工具、运行、审批、刷新、置顶、归档、更多、删除、警告、复制和编辑。每个图标在独立单元格中直接显示图形与中文能力名，不套默认底圈。

## 设置、列表与浮层

设置页的基础单位是分组。同一组共用一个 Group Surface，行内使用 0.5dp 发丝线。组标题、第一行与下方内容有固定间距。短页直接显示分组，不为统一制造空 Tab；复杂详情才用固定顶部分类。

设置行最小 56dp。裸图标 24dp，透明点击区 48dp；主标题 16/24，说明 12/18。图标不使用默认彩色圆底。

统一列表顺序固定为：置顶 → 未置顶文件夹 → 今天 → 昨天/星期 → 月分组。运行状态绿色并随时间淡出，10 天以上退为灰色。组折叠按钮在标题右侧，不显示数量，不额外占用正文。

能力、运行模式、审批、思考强度和模型选择使用同一 Overlay Surface。MCP 在窄浮层内展开；不回到六宫格大卡片。模型选择器的搜索与筛选并列，列表项底色必须清晰但不过度玻璃化。

## 两套皮肤

| 能力 | 经典 | 液晶玻璃 |
|---|---|---|
| 普通分组 | 纯白静态内容面 | 半透明白，保留背景色相但不实时模糊 |
| 主输入区 | 88–96% 填充，无实时模糊 | 42–68% 填充，22–30dp 模糊 |
| 浮层 | 接近实心、轻阴影 | 24–30dp 模糊，单向柔影 |
| 边缘 | 极细边界 + 轻阴影 | 局部受光 + 轻微折射，无闭合粗亮边 |
| 图标 | 裸图标 | 裸图标，反馈时出现短暂底光 |
| 性能回退 | 原生静态表面 | 静态玻璃，保留色相与层级 |

只有液晶玻璃允许更强的镜面受光和折射。经典不通过“玻璃感”建立层级，而依靠留白、颜色和排版。两者都禁止普通卡片实时模糊、持续漂浮、无意义旋转和每个图标底圈。

## 语音主视觉

语音球采用 VoiceOrbs 的视觉算法研究结果，并按 Android Compose Canvas 重写，不引入 React/WebGL 运行时：

- 经典：`1 · Plasma Orb`。多层等离子纹路、明亮内核、顶部镜面高光和随输入电平呼吸的柔光。
- 液晶玻璃：`13 · Waveform Ring`。中心是高透玻璃核，外圈由最近 128 个归一化 PCM 样本驱动，形成径向时域声纹环、旋转折射弧和播放态粉蓝辉光。

状态映射：聆听使用真实 PCM 波形；连接、识别和朗读可使用程序化节奏；错误使用珊瑚色静态光晕。不可见、空闲或 Reduce Motion 时停止逐帧动画。软件 Canvas 也有静态/Canvas 回退，不依赖 AGSL 才能显示。

## 动效

| 语义 | 时长 | 使用 |
|---|---:|---|
| Press | 90ms | 按压、颜色、短 scale；松开单次轻回弹 |
| State | 180ms | 开关、选中、状态胶囊 |
| Enter | 240ms | 小型内容进入 |
| Overlay | 300–340ms | 浮层进入，退出快 20–35% |
| Scene | 380ms | 会话/会议室等大场景切换；上限 420ms |

Q 弹感来自方向明确的弹簧：阻尼 0.78–0.88、刚度 360–540，最多一次轻微回弹。频繁交互、列表滚动和长按路径不反复弹跳。图表最多 420ms 一次性绘制。后台、低电量、窗口不可见或 Reduce Motion 时停止持续动画并改为 120ms 淡入淡出。

## 无障碍与性能

- 可点击目标至少 48×48dp，相邻目标至少 8dp。
- 正文对比度至少 4.5:1，大字号至少 3:1。
- 状态不能只靠颜色，必须同时有文字、图标或形状。
- 支持 200% 字体、320dp 窄屏、横屏、软键盘、分屏、TalkBack 和高对比模式。
- 宽屏正文最大可读宽度约 920dp。
- 每屏最多一个持续背景采样区；普通卡片零实时模糊；文字和图标永不进入折射层。
- 设备不支持采样、关闭模糊、低内存或软件 Canvas 时回退静态表面。

## 落地顺序

1. 冻结语义令牌与双皮肤，不再增加第三套皮肤。
2. 建立 1 套共享输入底层和 10 个输入视觉角色。
3. 建立 10 个动作角色，并替换直接写尺寸的按钮。
4. 接入 Material Symbols Rounded SVG，删除默认图标底圈。
5. 先迁会话输入、控制条、新建会话、能力/运行/审批/思考/模型。
6. 批量迁移 23 个搜索入口和设置分组。
7. 迁移统一列表、文件夹菜单、浮层、状态和危险确认。
8. 每完成一个功能组只验当前链路；不做无关全量回归。正式视觉与长期性能由手机安装后验收。
