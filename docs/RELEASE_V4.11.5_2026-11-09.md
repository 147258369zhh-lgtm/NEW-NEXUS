# Eta v4.11.5 开发与发布记录（2026-11-09）

## 版本信息

- 版本：4.11.5
- versionCode：2026110911
- 构建类型：Release
- 最低系统：Android 13
- 目标系统：Android 17 / ColorOS 17

## 数据备份与迁移

- 修复核心数据库版本清单滞后导致新版备份无法导入的问题。数据库与备份迁移清单现在共用 `ETA_DATABASE_VERSION`。
- `26 -> 27` 的 MCP 数据库迁移改为可重复执行，避免升级或恢复中断后因重复字段报错。
- 备份校验支持当前记忆状态：`butler_review`、`butler_approved`、`confirmed`。
- 修复上下文压缩覆盖完整运行日志的问题：压缩 history 前将原分块原子转挂为 journal，再写入摘要，并在大日志压缩时避免瞬时复制两份。
- 自动备份未选择目录时，明确提示选择可写文件夹后启用。

## 成本、运行统计与轨迹

- 整理运行统计页面层级，合并重复的趋势区域，统一卡片、字号、间距和图表动效。
- 优化 Token、缓存、费用、吞吐、耗时、工具成功率和用量完整度展示。
- 长运行记录继续通过分块存储和完整 journal 保留，摘要压缩不丢失原始轨迹。

## UI 与交互

- 自动任务、任务编辑、流程步骤、项目、MCP 调试、Skill 版本、语音设置、系统接管和备份中心按能力中心设计语言统一。
- 统计筛选及各弹窗的二级选项使用父弹窗内联展开，避免 Android 16/17 上层弹窗被父窗口遮挡。
- 统一页面进入、选择器展开、图表和状态变化的轻量动效，并补齐图标语义色。
- 修复 Virtual Display 对 API 34 类型的静态引用，降低 Android 13/14 兼容风险。
- 图片发送保持 1568 长边和 250 万像素模型预算。
