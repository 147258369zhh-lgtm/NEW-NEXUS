# P14 运行统计与轨迹

本轮将前端观察得到的临时计数改为 Runtime 收集、Room 持久化和实际可点击的统计页面。P14 整批仍未完成，下面明确区分本轮实现与剩余出口。

## 已实现

- `AgentRuntimeSession` 在事件投影/回放前收集一次，页面重连和回放不重新计数。聊天、会议成员、定时任务、语音归档入口、准备失败和取消使用同一收集链路；进程内无工具回复使用独立记录 ID，保留原始交接失败的诊断。
- 用量以模型轮次为键更新，后续累计 usage 替换之前计数；缺失字段保留未知，真实上报零保留零。总轮数按实际唯一轮次统计，展示输入/输出覆盖，部分上报合计不能当作完整账单。
- 工具区分成功、失败和未完成/未知，托管工具单独识别；重复开始/缺省结果不抹掉已知结果。记录请求次数、重试/备用切换、完成压缩与初始/工具附加图片字节数。
- 主/备用模型分别记录模型身份、用量、轮次、工具结果、请求、图片和压缩信息。独立子 Agent 与分块摘要另建请求记录，主运行用量保持独立，费用按各记录相加，不把子请求重复加进主模型。
- `eta_run_metrics.db` 现为 v2。运行汇总、模型尝试、有界轨迹和子请求在单个事务内更新；拒绝较旧版本与终态后的写入。每运行的待写快照合并，避免流式消息造成持续快照排队。父记录使用 Upsert，更新轨迹/模型时显式替换对应数据，不用 REPLACE 误删子请求。
- 后台采集与 Activity/RuntimeService 退出独立，完成/取消时固定耗时。进程重启把旧进程遗留运行标为中断，并追加中断轨迹；不把两次启动间隔算作执行耗时，也不自动重跑旧工具。
- 导入旧 `eta_run_metrics/records_v1` 一次，持久迁移标记防止清除后旧记录重新出现；旧版无法确认的零和工具结果保留未知，原偏好文件作为迁移证据保留。
- 保留最近 200 条已结束运行和全部活跃运行；清除操作只清除已结束记录及其模型/轨迹，保留聊天与任务结果。

## 页面与导出

- 延续 Miuix 页面骨架、卡片、菜单、宽屏适配和字体样式；提供来源、主模型、项目、状态、时间范围筛选，筛选状态可恢复。
- 概览显示已上报 Token、工具结果与覆盖率。最近七天按本地日历日期显示每日运行次数；只统计当前筛选和保留范围，历史保留不足不能当作完整趋势。
- 列表打开真实运行明细，显示固定耗时、模型尝试和时间顺序轨迹。聊天/会议来源存在时才启用跳转；已删除或尚未存档的来源有状态说明。
- 轨迹最多保留 512 步，显示省略数量；重复用量、子 Agent 进度和补充事件不会无限刷屏，汇总计数不随轨迹裁剪而丢失。
- 当前筛选或单条记录可以通过系统文件选择器导出 JSON。单次最多 256 条/16 MiB；一致性读取后先写应用临时文件，再发布到所选位置。保存结束并成功关闭后才显示完成，取消/失败清理临时文件；目标文档可能留下部分内容，界面明确提示。
- 导出保留 null/零与覆盖、来源 ID、模型、版本、状态和结构化轨迹，排除原始会话、提示词、工具参数、命令、结果、图片和凭据。所选记录在保存前被清除时，显示实际导出和缺失数量。
- 导出具有一分钟的操作总时限，并支持主动取消；第三方文件提供者底层 Binder 是否及时响应取消取决于 Android/provider，不能保证任意远程提供者都立即退出。

## 备份、迁移与验证

完整备份在数据库检查点前等待已接受的统计写入，把统计数据库的记录数计入 `runtime` 分区。统计数据库、模型/轨迹、子请求、价格配置和历史价格随完整备份恢复。迁移清单修正为实际数据库名称与版本：主库 v24、会话扩展 v4、会议 v5、A2A v2，以及统计 v2。v1→v2 迁移保留旧记录，不能猜旧协议/单价，旧计价字段保留未知。

专项自动验证：57 项，56 执行通过、1 项既有 Linux/POSIX 平台测试跳过、0 失败/错误。覆盖累计用量去重、null/零、模型对账、回放/取消终态、隐私和轨迹上限、Room 清除/迁移/并发/裁剪/中断恢复、SAF 导出失败/取消、DST 本地日期，以及完整备份恢复统计。最终全量测试 2329 项，2180 执行通过、149 平台跳过、0 失败/错误；随后最终 Kotlin 编译/Lint 成功，Lint 0 错误、438 警告、2 提示。详细证据见本轮继续开发记录。

## 本次继续：价格与独立请求

- 供应商 ID＋实际模型标识对应手动单价。输入/输出必填，缓存读取/写入可留空表示未知或填 0 表示免费；每百万 Token、ISO 4217 币种、最多 8 位小数、上限 1,000,000。拒绝负数、指数和分隔符，费用全程 BigDecimal，极小正金额不显示为免费零。
- 主模型尝试、备用尝试和每个独立子请求开始时捕获当时价格版本与时间。Service 构造不查同步 Room；执行线程捕获价格，查询失败保留未知，不中断 Agent。修改/移除配置不重算历史，清除运行历史不清除价格配置。
- OpenAI 输入扣除缓存、输出不重复计 reasoning；Anthropic 输入为未缓存输入，缓存读取和创建单独计；Gemini Interactions 输出加独立 thought 用量。原始上报值继续保存，累计缓存补充后重新归一化，不重复加总。
- 未知协议、负数/不可能的计数、缺用量/缺价保留未知。Gemini 托管工具额外输入不猜费用。重试无法逐 HTTP 尝试对账时只显示保留的已知部分，不能标完整账单；不同币种分别合计，不进行隐式兑换。
- SubagentExecutor 将真实内部事件交给独立 scope；每次续接是新的请求组。ModelClient→Loop→ContextSession→Compactor→Summarizer 传递 scope，所有分块/多层摘要逐请求登记，子 Agent 自己压缩时保留父子关联。
- 独立请求保存模型、价格、用量、请求/重试/工具、耗时、状态和上级 scope，不保存正文或参数；不限制为 8 个子请求。摘要失败仍保留实际付费用量；主运行取消/终止冻结仍活跃的子请求，迟到用量/终态不能改写记录。重启补中断状态，不重跑旧任务或计入停机时间。
- Miuix 统计页新增价格列表/搜索和独立编辑页，键盘类型、加载/失败/重试、删除确认和恢复填写状态与现有页面一致。统计中心和明细展示分币种费用、覆盖与当时单价；独立请求明细展示真实层级和状态。
- 诊断 JSON 升为 v2，包含归一化计价字段、精确金额字符串、价格版本与全部独立请求；依然排除会话正文、提示词、参数、结果和凭据。原 SAF 的取消/超时/临时文件/关闭成功出口保持。
