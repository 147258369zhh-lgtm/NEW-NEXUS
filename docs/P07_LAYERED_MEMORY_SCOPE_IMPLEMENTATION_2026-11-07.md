# P07 分层记忆作用域实现

本轮把审查报告里的“分层标题”升级为真正的持久作用域，同时保持旧版 `memory/MEMORY.md` 完全兼容。

## 已实现

- 新增全局、项目、会话、会议、任务作用域，作用域 ID 只允许安全的字母、数字、下划线和短横线。
- 每个局部作用域独立保存为 `memory/scopes/<type>/<id>/MEMORY.md`，原子写入和 SHA-256 revision 保护沿用现有存储。
- Runtime 根据会话/会议绑定的项目注入全局、项目和当前运行作用域；没有绑定时继续只使用全局记忆。
- `memory_get` 支持 `scope=global/project/current`；`memory_write` 的 `layer=project/task/working` 会写到当前允许的局部作用域，模型不能指定任意路径。
- 修复角色剧情记忆写入忽略 `layer` 的问题。
- 记忆页增加 Miuix 作用域下拉选择器、作用域名称和未保存切换保护，沿用既有卡片、间距和预览/编辑布局。
- JSON 备份新增 `memoryScopes`，导出、校验、导入和失败回滚均覆盖局部记忆；旧备份没有该字段时仍可恢复。

## 设计边界

本轮没有引入向量数据库或后台自动写入。Markdown 仍是用户可读、可编辑、可迁移的事实来源；自动提取、去重和语义检索应在下一阶段建立确认队列后再开启，避免模型把临时内容静默写成长久事实。

## 验证
