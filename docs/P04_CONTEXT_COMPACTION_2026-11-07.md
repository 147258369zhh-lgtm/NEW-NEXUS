# P04 上下文与压缩

日期：2026-11-07。

- 会话上下文圆圈继续支持长按单独设置，新增自定义 token 长度输入并限制在 1,024–16,000,000；空值恢复模型默认，保存仍受模型已知窗口上限约束。
- 压缩器新增安全范围选择 API：范围必须位于系统消息之后，不能切断 tool call/tool result 配对，也不能选中观察消息；原子候选提交和失败保留原上下文的规则不变。
- 默认自动压缩继续使用原来的完整批次边界；手动范围只改变要摘要的区间，范围外消息以无状态形式保留，避免旧 provider ephemeral state 与新摘要混用。

新增范围边界单元测试，已有压缩、取消、恢复和上下文覆盖测试继续执行。本批已接通手动范围选择器：在上下文圆圈长按设置页输入历史索引范围（例如 `0-8`），请求通过 Runtime wire 传递到压缩器；系统提示、观察消息和未闭合工具链仍由压缩器拒绝，留空继续自动选择。独立压缩模型的供应商配置仍需后续接线，当前不会擅自把摘要发送到另一家供应商。
