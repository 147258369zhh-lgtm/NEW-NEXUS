# P09 MCP 与 Skill 治理

新增 MCP 工具治理层：工具名必须经过命名校验，输入 Schema 限制在 64 KiB 内，带有删除、发送、支付、执行等高风险语义的工具标记为 `REVIEW`；不合规工具不会加入当前 run 的冻结目录。现有 Skill 安装锁、冲突确认和 MCP 设置页继续复用。

资源/模板现已进入独立页面：分页搜索、必填参数、实际 `prompts/get`、有界 UTF-8 预览、HTTP/SSE 取消与一分钟总时限。仅资源服务器无需 tools/list；旧协议声明和现代方法探测区分“不支持”与真实失败，目录达到限制显示未完整加载。

本批补上了显式工具调试入口：启用工具后可在服务器详情输入 JSON 参数并单次调用，结果限制为有界预览；调用复用同一协议协商、认证和取消生命周期，不会把调试调用注入聊天上下文。批量配置、OAuth 与完整 Skill 编辑/测试/导出/更新/回滚闭环仍需后续实现。
