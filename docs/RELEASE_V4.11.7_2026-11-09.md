# Eta v4.11.7 UI 精修与入口整理

## 版本信息

- 版本：4.11.7
- versionCode：2026110913
- 目标：Android 16 / Android 17、ColorOS 16 / ColorOS 17
- 构建类型：Release

## 入口与导航

- 设置页移除与外层功能重复的“本地模型”和“A2A 协作”入口。
- 本地模型继续保留在“模型提供商”内；A2A 继续保留在“能力中心”内，底层能力与路由未删除。
- 将系统接管、厂商助手兼容、Gemini、语音唤醒与手势控制的零散单入口合并为“系统助手与手势”集合。
- 会话侧栏底部顺序调整为“会话、会议室、设置”。

## 视觉层级

- 共享卡片升级为双层细边、主题高光、轻量阴影与更清晰的内侧反光。
- 图标底座增加径向光泽、内外双描边和更克制的语义色发光。
- 页面背景减少可见颗粒，改为低对比斜向柔光与双色空间渐变。
- 状态胶囊加入状态灯、轻渐变底和动态内容切换。
- 弹窗底部操作区加入渐隐分隔线；弹窗内选择器增加统一材质、阴影和选中勾底座。
- 设置与模型提供商使用统一的分组标题标记；厂商图标增加细边与柔和投影。
- 模型提供商列表、主页面功能卡、提供商配置分组共享新材质。

## 兼容性约束

- 不引入新的系统级权限或后台服务。
- 选择器继续在父弹窗内展开，避免 Android 16 / 17 的二级窗口层级错位。
- 视觉变化仅使用 Compose 绘制与现有 Miuix 组件，不新增原生依赖。
