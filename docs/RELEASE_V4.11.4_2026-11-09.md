## 本轮完成

### 1. 启动闪退修复

真机日志确认，4.11.3 启动后崩溃的原因是 LaTeX 环境正则中的花括号转义不兼容 Android ICU：

```text
java.util.regex.PatternSyntaxException
\\begin\\{[^}]+}.*?\\end\\{[^}]+}
```

本次移除了这条高风险正则，改为边界可控的直接解析逻辑。矩阵、普通公式和不完整公式都不会再因正则编译失败让界面崩溃，并新增了对应回归测试。

### 2. 主会话与会议室体验

- 会议室采用“主持人监督器 + Agent 作为工具”的受控拓扑。主持人接收用户原始任务、拆分工作、分派参与者并汇总结果。
- 用户直接 `@` Agent 时可定向执行；未指名时由主持人选择参与者；参与者之间不直接共享无关上下文。
- 会议室支持受限自建专家 Agent、独立模型配置、共享头像和头像外的状态点。
- 会议室设置移入会议室右上角管理菜单；会议室支持删除、导出、归档等会话管理能力。
- 会议室与普通会话接入项目文件、导入文件和输出文件；产出支持导出和分享。
- 上下文进度圈改为绿、黄、红渐变，压缩时带呼吸反馈。
- 主页面滑动手势重新划分判定范围；修复中间滑动打开错误侧栏、会话/会议室切换和详情滑出不稳定问题。
- 会话历史层级、字号、圆角、材质、文件夹包含关系、状态点、置顶/删除操作和底部导航比例继续统一。
- 会议室输入区与普通会话输入区对齐。

### 3. Markdown、公式、代码与图片

- 公式继续使用原生 Compose 渲染，不依赖 WebView，避免 WebView 崩溃和进程退出。
- 修复 LaTeX 环境解析造成的启动闪退。
- Markdown 文档、内联内容、代码高亮、图片加载和流式解析保持统一的块模型。

### 4. A2A 双向协作与后台服务

- A2A 服务改由独立进程中的前台 Service 持有，使用常驻通知、`START_STICKY` 和 partial WakeLock，摆脱 Activity/ViewModel 生命周期。
- 声明 `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC`、`WAKE_LOCK` 和电池优化相关权限。
- `stopWithTask=false`；`onTaskRemoved` 不停止监听。
- `onStartCommand` 在系统重建时会重新加载 token、配置、端口和对端策略；启动失败使用指数退避重试。
- 每 15 秒本地探测 `127.0.0.1:43121`，连续两次失败自动重启监听，UI 状态来自真实探测而非开关变量。
- 提供忽略电池优化授权入口、应用电池设置入口，以及 ColorOS、MIUI、EMUI 后台活动和最近任务加锁提示。
- 保留已经验证的标准方法名与 PascalCase 双向别名；保留按请求 Host 动态生成 Agent Card URL；保留局域网直连与外部 Tailscale 传输切换。
- 保留 A2A 请求入口的幂等运行时初始化，覆盖独立进程和后台唤醒。
- 对端工具权限按节点 ID、`X-A2A-Peer-Id`、`X-A2A-Client-Id` 或 token 指纹分组：
  - 只读档默认开启：设备状态、网络、上下文、文件读取与列举、最近通知和最近应用活动。
  - 受限档显式授权：文件写入与编辑、终端、启动应用、打开 URI、设置剪贴板。
  - 高危档永久关闭：自动化、Subagent、终端 daemon 和从 GitHub 安装 Skill。
- 同一次入站请求使用同一份工具白名单构建工具定义和执行策略；没有允许工具时不向模型传入 `tools`。
- 入站执行复用与普通聊天相同的 Agent Runtime 循环和工具解析器。
- 增加 DSML 与未解析 `invoke` 输出清洗；覆盖全角 `｜｜DSML｜｜`，拒绝泄漏原始协议标记。
