## 1. 当前结论

Eta 目前是在 Mangi-11/Eta 的 Kotlin/Compose Android 底座上开发的增强分支。保留原有 Miuix/Mica 视觉语言，并把新增能力尽量隔离在 `io.github.mangi.eta.fork` 下，便于继续吸收上游更新。

当前已经形成这些可用模块：

- 正常对话、会议室、A2A 入站任务和定时任务共用 Agent Runtime 接线。
- 会议室采用“主持人监督器 + Agent 作为工具”的受控拓扑，支持单 Agent、多 Agent 并行和主持人分派。
- 会话支持置顶、文件夹、折叠、手动归档、按闲置天数自动归档、Markdown 导出和归档恢复。
- 会议室支持独立归档、恢复、导出、删除、参与者进程查看和状态区分。
- 子 Agent 支持独立 provider/model/reasoning、八类权限预设、单项工具选择和普通会话创建。
- 完整备份包含数据库、文件、设置、模型/MCP/A2A/语音凭据，并支持密码加密导出与跨设备导入。
- A2A 已具备 Agent Card、出站调用、入站监听、Bearer 校验、持久任务、轮询、取消、幂等和进程恢复。
- 定时任务支持间隔、每天、每周计划，以及持久运行、取消、受控重试和退避。
- 学习模块支持候选、证据、用户确认、冲突保护、晋升、版本和回滚。
- 工作区文件管理支持新建、重命名、复制、移动、删除、预览、导出和系统分享。

目前不能宣称“全部需求均已完成”。主要缺口是 A2A 的公网/跨 NAT 双向可达、tsnet/Headscale 真机落地、会议室最新包的三条路径完整真机回归、Omni 完整皮肤、分支图、数据统计、灵屏、流体云，以及 MCP/Skills 的深度增强。

## 4. 需求逐项状态

状态含义：

- **已完成**：代码、单元测试或构建已证明。
- **已实现，待真机**：代码和自动测试已落地，但最新安装包的端到端交互没有完整回归。
- **部分完成**：主路径存在，但范围或质量仍未达到原要求。
- **未完成**：没有可信实现，不能把规划文档当成代码。

## 5. 上游更新整合方案

当前 `.git` 发布后，建议把新仓库作为 `origin`，把 `Mangi-11/Eta` 作为只读 `upstream`：

```text
origin    https://github.com/147258369zhh-lgtm/ETA-.git
upstream  https://github.com/Mangi-11/Eta.git
```

同步原则：

1. 每次从 `upstream/main` 建立只读基线，不使用整目录覆盖。
2. 上游新增且本地不存在的文件，先做权限、网络和默认开关审查。
3. 上游修改而本地未修改的文件，可以直接接受上游更新。
4. 双方都修改的文件，比较上游 `old → new` 与本地 `old → fork`，只移植上游改进。
5. `fork/*` 新增能力保持独立，公共接线文件优先人工审查。
6. 每批同步至少运行 Kotlin 编译、受影响测试和 Debug APK 构建。

现有 `scripts/check-upstream.ps1` 可在无 Git 元数据时做三方文件审计；发布后仍可用于差异报告，但不能替代分支审查。

## 6. A2A 集成方案文档的落地结论

已审阅桌面文件 `[本地交付目录]/A2A_App集成方案.docx`。方案采用 Headscale 控制面、tsnet 用户态数据面和现有 A2A HTTP 服务，方向合理，但当前尚未进入主构建。

实施前必须依次满足：

1. 锁定 Go、gomobile、tsnet、Headscale、NDK 和 AAR 校验和。
2. 在目标 Android 真机验证 netlink 限制修复、启动耗时、熄屏保活、Wi-Fi/移动网络切换和 APK 体积。
3. 用一次性配对码或二维码签发短期凭据，凭据经 Keystore 保存，控制面可撤销单设备。
4. 服务只绑定 `127.0.0.1`，由 tsnet 暴露固定端口，Agent Card URL 使用实际 tailnet 地址动态生成。
5. 用精确 peer ACL 和 Bearer 双重鉴权，禁止把整个 tailnet 段视为可信。
6. 完成手机→电脑、电脑→手机、重复投递、轮询、取消、断线重连、VPN 共存和继电器回退。

在上述 Gate 完成前，现有“手动 Agent Card + 局域网/HTTPS 可达地址”仍然是实际可用的 A2A 方式。

## 7. 已知风险与技术债

- 最新包只完成安装和少量 UI 观察，不能在未完成回归前标注为“生产可用”。
- Windows 跳过 146 项 POSIX/PRoot/Root 测试，Linux CI 和真机仍需执行。
- 会议室仍使用独立页面 Composable，只共享 App Shell 和视觉 token，不是用户期望的物理同一个聊天页面。
- 文件搜索目前是当前目录过滤，不是跨目录全文搜索。
- 文件夹是一级模型，不支持父子多级文件夹。
- 加密备份存在，但跨设备真实恢复仍是最重要的高风险验收项。
- A2A 协议双向代码已具备，但“没有可达地址”仍是跨网络双向调用瓶颈。
- 定时任务受 Android 后台限制影响，尚未完成长期节电和 ROM 兼容测试。
- Omni 皮肤、流体云、灵屏、分支图、统计中心仍属于完整功能缺口。
- 多 Agent 并行会放大模型费用和工具副作用；当前依靠并发上限、受控路由和不可自动重放降低风险。
