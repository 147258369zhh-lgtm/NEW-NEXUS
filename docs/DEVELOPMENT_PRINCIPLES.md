# 持续开发原则

用户确认于 2026-11-07：参考项目用于学习和比较，不以复制功能或搬运代码为开发目标。允许在许可范围内复用，但必须结合 Eta 自身架构改进，交付质量以代码设计、实际可靠运行、功能完整性和 UI 易用性为准。

- 对照实际源码与运行机制，不以 README 或界面数量判断完成度。
- 复用保留来源与许可证，控制依赖和模块边界，保护已有功能。
- UI 统一沿用现有 Miuix 和会议室设计语言，认真核对图标、字体、间距、层级、小屏、大字体与状态反馈。
- 交付必须包含验证结果、可操作的使用说明和如实记录的限制；不能把配置入口或示例视为运行成功。
- 比参考实现更强、更细、更好用是持续验收目标，未完成的部分明确记录并继续开发。
