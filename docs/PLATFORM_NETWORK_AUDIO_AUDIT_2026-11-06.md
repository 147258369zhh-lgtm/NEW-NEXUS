## 局域网连接修复

`AgentHttpClient` 统一接入 `LocalNetworkFailureInterceptor`，应用各进程初始化时提供 application context。客户端已创建后也读取最新授权状态，不缓存授权结论，不新增权限弹窗，不要求云端服务先获得局域网权限。

发生 Socket/连接超时/主机解析失败，目标是显式私网 IP、链路本地地址、IPv6 ULA 或 `.local` 名称，且 Android17 局域网权限确实未授予时，返回独立的 `LOCAL_NETWORK_PERMISSION_REQUIRED`。提示到“设置 → 权限健康”授权，并说明仍失败需要检查地址及网络；不将缺权限描述成所有连接故障的唯一原因。

- 模型请求保留该错误和提示，停止模型自动重试，避免等待期间重复请求；用户授权后可重新发起。
- MCP 发现/调用复用同一客户端，现有错误区域能显示具体提示。
- 语音 HTTP/WebSocket 握手复用该客户端，映射到权限错误，保留授权指引。
- 模型目录、网页工具及其他复用该客户端的连接也继承诊断。
- 请求成功时不检查/拦截权限；HTTP 返回码、TLS、协议错误、取消和公网/回环失败保持原意。Android13/16 不检查 Android17 专属权限。

这是**连接失败诊断**。不额外解析普通域名，不探测局域网，不改变路由、代理或重定向政策。普通域名解析到私网、公网地址所在本地网段、响应体读取阶段及重定向后的实际目标，尚无完整路由归因；不宣称所有局域网故障都已识别。WebView、原生 socket、PRoot 子进程、tsnet 及入站 A2A 不是本拦截器的覆盖范围，继续按 P09/P12 验证。
